# AI tells

**Patterns that make an interface look generated.** The agent never adds them; each appears only when the user asks for it.

1. **Side border.** A colored left or right border above 1px on cards, list rows, callouts or alerts.
2. **Section numbers** (01 / 02 / 03, `001 ·`), unless the order itself is information the user needs.
3. **The hero-metric template:** a big number, a small label, supporting stats, an accent.
4. **Fake product screenshots** built from divs (dashboards, task lists, terminals): use a real screenshot, a real component, or nothing.
5. **Decorative status dots:** a dot only for a real state (online, available).
6. **Scroll cues:** "Scroll", "Scroll to explore", arrows, mouse-wheel icons.
7. **Version labels** (v2.0, BETA, Build 0048) in the hero or the footer, unless the product really is in preview.
8. **Place and time strips.** Strips with a city, the time or the weather.
9. **Pills or labels over images:** the caption goes under the image.
10. **Invented photo credits:** only the name of a real photographer.
11. **Decorative word strip.** A strip of decorative words at the bottom of the hero ("DESIGN · BUILD · SHIP").
12. **Score bars** with a filled track to compare values on a page in site mode: show the number.
13. **Duplicate calls to action.** Two calls to action with the same intent and different labels ("Contact us", "Let's talk"): keep one.

**Sources:** impeccable (1–3), taste (4–13).
