**Language**

- **Language:** a tertiary Button with the two-letter code ("IT"), no icon. It opens the Menu with the languages, each in its own name (Italiano, English) and with its own lang attribute, the current one with a check. Picking one changes the code on the button. Its label contains the visible code ("Language: IT"). It exists only when the project is multilingual (Start here).
- **Current language:** in the Language menu: font-family `title-sm`; font-size `title-sm`; font-weight `title-sm`; line-height `title-sm`; letter-spacing `title-sm`.
- **Language options:** after the links, a row built like a link with sub-links (chevron, no icon) whose sub-links are radios. The checked one carries a check at the end: font-family `title-md`; font-size `title-md`; font-weight `title-md`; line-height `title-md`; letter-spacing `title-md`. The others keep the check's space: their check: visibility hidden.
