# Menu

**Uses:** Avatar, Button, Tooltip, Overlay rules.

**Purpose:** the one menu of Kore. Every list that opens from a trigger is this menu: action menus, Select, Combobox, the language menu, the sub-links of the top bar and the folded levels of a Breadcrumb. No variant changes its look.

- **Hierarchy:** the items come first, in their groups; the group titles and the separators only order them. The highlighted item is the focal point (The One Winner Rule): the only one with a fill. A selected option or the current link follows in `title-sm`; the other rows in `body-md` `ink`; the group titles in `label-md` `mute` only guide.
- **Elements:** the Menu's own: wrapper, menu, item, item icon, trailing, matched text, separator, group title, email row, no-match note, sub-menu, back row, back label. Other components: the trigger (Button), the profile trigger's Avatar (Avatar), the disabled item's Tooltip (Tooltip).
- **Wrapper:** the trigger and its menu, so the menu is placed against its trigger. The trigger has `aria-haspopup`, `aria-expanded` and `aria-controls` pointing to the menu. position relative; display inline-flex.
- **Menu:** a dropdown at its trigger at every screen size, phones included, never a sheet; drawn inside its edge, no shadow. It opens below its trigger with its start edge on the trigger's start edge, and stays `space-2` from the screen's edges. Past five and a half items (so the cut item shows it scrolls) or the screen's height, it scrolls inside. Its width is at least `space-48` + `space-8` and never narrower than its trigger; it grows to its widest item. position absolute; top calc(100% + `space-2`); inset-inline-start 0; z-index `zIndex-dropdown`; min-width max(calc(`space-48` + `space-8`), 100%); width max-content (the CSS keyword, not the token); max-height calc(5.5 × `space-10` + `space-1`); overflow auto; background `surface-float`; outline `line-thin` solid `hairline`; outline-offset −`line-thin`; border-radius `rounded-md`; padding `space-1`; display flex; flex-direction column; gap 0.
- **Menu above:** only when there is no room below: top auto; bottom calc(100% + `space-2`).
- **Menu at the end:** only when there is no room on the end side: inset-inline-start auto; inset-inline-end 0. The menus of the Sidebar open on the end side of the panel (Sidebar).
- **Menu open:** opacity from 0 and a move down by `space-1`: animation `duration-base` `ease-out`.
- **Menu closing:** it fades to 0 in `duration-fast` with `ease-in`, and stays so until it is hidden.
- **Reduced motion:** the menu only fades in: animation-name fadeIn.
- **Item:** its own hit area, touching the next, the one exception to Touch targets. A menu shows no keyboard shortcuts. position relative; display flex; align-items center; gap `space-2`; width 100%; height `space-10`; padding 0 `space-2`; border-radius `rounded-sm`; color `ink`; text-align start; white-space nowrap; cursor pointer; text-decoration none; font-family `body-md`; font-size `body-md`; font-weight `body-md`; line-height `body-md`; letter-spacing `body-md`.
- **Item highlight:** one item at a time. A mouse hover (hover: hover) moves focus to the item (Select and Combobox options keep focus on their field and move `aria-activedescendant`). On hover and on the active option: background `surface-float-active`. On :focus-visible: outline none; background `surface-float-active`. The background changes in 0s.
- **Item icon:** optional, an `icon-sm` icon on the left, `space-2` from the label. color `mute`.
- **Trailing:** at most one `icon-sm` icon on the right: the check of a selected option or the chevron of a sub-menu. display flex; margin-inline-start auto; padding-inline-start `space-6`; color `ink`.
- **Hidden check:** on the options that are not selected and on links without `aria-current`, the check keeps its column: visibility hidden.
- **Selected option:** a single choice (`aria-selected="true"`, `aria-checked="true"`), and the current link of a navigation menu (`aria-current`): a check on the right. font-family `title-sm`; font-size `title-sm`; font-weight `title-sm`; line-height `title-sm`; letter-spacing `title-sm`.
- **Matched text:** the part of a label that matches the typed text, a `mark`. background none; color inherit; font-family `title-sm`; font-size `title-sm`; font-weight `title-sm`; line-height `title-sm`; letter-spacing `title-sm`.
- **Disabled item:** it stays reachable with the arrows (`aria-disabled`) and a Tooltip says why when it is not obvious. color `stone`; cursor not-allowed; background none, also on hover.
- **Disabled icon:** color `stone`.
- **Destructive item:** last, in a group of its own, with `ink` text (red text fails contrast on the active surface in dark). Its icon: color `danger`.
- **Item list:** the items of a `listbox` or a group. display flex; flex-direction column.
- **Separator:** between groups. position relative; height `space-4`; flex none.
- **Separator line:** the separator's ::before, inset so it lines up with the text. content ""; position absolute; top `space-2`; inset-inline `space-3`; border-top `line-thin` solid `hairline`.
- **Group title:** the first row of its group (Group titles in Hierarchy). It is not an item: the arrows skip it and it cannot be selected. It scrolls with its group. The group is a `group` with `aria-labelledby` pointing to it. display flex; align-items center; height auto; padding 0 `space-2` `space-2`; color `mute`; font-family `label-md`; font-size `label-md`; font-weight `label-md`; line-height `label-md`; letter-spacing `label-md`.
- **Email row:** padding `space-2`; color `mute`; font-family `body-md`; font-size `body-md`; font-weight `body-md`; line-height `body-md`; letter-spacing `body-md`. Only in the profile menu: the account's email as its first row, then a separator. The arrows skip it and it cannot be selected. Apart from the email, a menu shows only rows to choose and group titles.
- **Profile trigger:** width calc(`space-10` + `space-1`); height calc(`space-10` + `space-1`); border-radius `rounded-full`; corner-shape round. A tertiary icon Button holding a default Avatar (initials or photo); its hover is a circle around the Avatar and the focus marks follow the same radius. The button carries the accessible label and its Tooltip, both naming the account menu; the initials are `aria-hidden` and the photo has an empty alt text.
- **No-match note:** outside the `listbox`, centred: what found nothing, then what to do (Combobox, Select). padding `space-2`; color `mute`; white-space normal; display flex; flex-direction column; gap `space-1`; text-align center; font-family `body-md`; font-size `body-md`; font-weight `body-md`; line-height `body-md`; letter-spacing `body-md`.
- **Sub-menu:** only in action menus, and one level only: a sub-menu never opens another. Select, Combobox and navigation menus have none. It looks as the menu. The parent item shows the chevron as its trailing; the parent item and its sub-menu sit in their own wrapper (display flex). It opens on the end side of the parent menu, `space-2` from its edge, with its first item on the parent item: top −`space-1`; inset-inline-start calc(100% + `space-1` + `space-2`).
- **Sub-menu at the start:** with no room on the end side: inset-inline-start auto; inset-inline-end calc(100% + `space-1` + `space-2`).
- **Menu with a sub-menu:** it never scrolls, or it would clip the sub-menu: overflow visible; max-height none.
- **Drilled sub-menu:** with no room on either side (on a phone two menus do not fit side by side), the sub-menu takes the place of the menu's content: the parent menu's other rows and the parent item are display none; the sub-menu: position static; outline 0; padding 0; min-width 0; animation none.
- **Back row:** the first row of a drilled sub-menu, shown only then: an item with the left chevron that returns to the parent menu. display none; in a drilled sub-menu, display flex.
- **Back label:** it says which menu the user returns to. font-family `title-sm`; font-size `title-sm`; font-weight `title-sm`; line-height `title-sm`; letter-spacing `title-sm`.
- **Drill motion:** both swaps: the old rows fade out and the new rows fade in whole in `duration-fast`, and the menu's edge moves to the new size with clip-path in `duration-base` `ease-out`; never animate its height. Under reduced motion the content only fades.
- **Sub-menu opening:** click, Enter, Space or →; with a mouse also hovering the parent item, after `duration-base`. The same delay applies before it closes when the pointer moves to another item, so crossing it diagonally does not close it.
- **Sub-menu keyboard:** focus goes to its first item; ← or Escape closes only the sub-menu and returns focus to the parent item. In right-to-left languages the arrows swap.
- **Sub-menu roles:** the parent item is a `menuitem` with `aria-haspopup="menu"` and `aria-expanded`; the sub-menu is a `menu`.
- **Keyboard:** Enter, Space or ↓ opens and focuses the first item (the selected one in a choice); ↑ ↓ Home End move, and ↑ ↓ go on from the other end; Escape closes and returns focus to the trigger; Tab closes.
- **Roles:** they follow the content: `menu` and `menuitem` for actions, `menuitemradio` for a choice in a menu, `listbox` and `option` for Select and Combobox; the sub-links of a navigation bar are a list of links under a button with `aria-expanded`.
