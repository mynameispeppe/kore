**Settings group**

- **Settings group:** an optional group titled Settings with the choices the project offers (language when it is multilingual, theme, units). Each is a row with an icon that opens in place into its options, radios in a `radiogroup`.
- **Option:** a row that is a radio, with a check at the end: margin-inline-start auto.
- **Selected option:** `aria-checked="true"`. font-family `title-sm`; font-size `title-sm`; font-weight `title-sm`; line-height `title-sm`; letter-spacing `title-sm`.
- **Hidden check:** on the options that are not selected the check keeps its column: visibility hidden.
