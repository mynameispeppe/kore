# Segmented control

**Purpose:** two to four short options, one always selected, that switch a view of the same content.

- **Use:** for two to four short, mutually exclusive options that switch a view (The Working Memory Rule); for more options, use a select.
- **Hierarchy:** the selected segment is the focal point (The One Winner Rule): the only one with a `surface-card` background, its label in `ink`; the other labels in `label-md` `mute`.
- **Elements:** the Segmented control's own: group, segment, hit area, selected background, view.
- **Group:** it hugs its segments, never stretches to full width. Every segment is as wide as the widest one, so the selected background keeps one size. position relative; display inline-grid; grid-auto-flow column; grid-auto-columns 1fr; align-items center; gap `space-3`; height `space-12`; padding `space-2`; border-radius `rounded-lg`; background `surface-elevated`; outline `line-thin` solid `hairline`; outline-offset −`line-thin`; align-self flex-start.
- **Segment:** an inline button, `space-3` from the next (Adjacent targets). position relative; height `button-sm`; padding 0 `space-3`; border-radius `rounded-sm`; color `mute`; font-family `label-md`; font-size `label-md`; font-weight `label-md`; line-height `label-md`; letter-spacing `label-md`; outline `line-thin` solid transparent, for forced colors; outline-offset −`line-thin`; transition color `duration-base` `ease-in-out`.
- **Hit area:** the segment's ::before, calc(`space-10` + `space-1`) square, centred on the segment. content ""; position absolute; inset calc((`button-sm` − (`space-10` + `space-1`)) / 2).
- **Segment hover:** only with a mouse (hover: hover): color `ink`. A background would not stand out on `surface-elevated`.
- **Selected segment:** color `ink`.
- **Segment focus:** around the focused segment, never around the whole group. On :focus-visible: outline none, changed in 0s; the corner marks of States, following `rounded-sm`.
- **Selected background:** the group's ::before, one segment wide, under the selected segment. It slides from the old segment to the new one, never by moving left or width, and does not move on first render. content ""; position absolute; inset-block `space-2`; inset-inline-start `space-2`; width calc((100% − 2 × `space-2` − (segments − 1) × `space-3`) ÷ segments); border-radius `rounded-sm`; background `surface-card`; outline `line-thin` solid `hairline`; outline-offset −`line-thin`; pointer-events none; transform translateX(calc(selected index × (100% + `space-3`))), × −1 under `[dir="rtl"]`; transition transform `duration-base` `ease-in-out` (Moving from one place to another).
- **Reduced motion:** no slide. The selected background: display none; each segment: transition `duration-base` `ease-in-out` on background-color, outline-color and color; the selected segment: background `surface-card`; outline-color `hairline`.
- **Disabled:** the group carries `aria-disabled="true"` and every segment has the disabled attribute, so none is in the Tab order; no hover; the selected one keeps its `surface-card` background; every segment: color `stone`; cursor not-allowed.
- **View:** what the group switches, under it. color `body`; font-family `body-md`; font-size `body-md`; font-weight `body-md`; line-height `body-md`; letter-spacing `body-md`; font-variant-numeric tabular-nums.
- **View motion:** the view follows the direction of the selected background; its frame (card, box) stays still and only what is inside it moves. The old view leaves with `duration-fast` and `ease-in`, fading out and moving `space-6` toward the side it is left behind on; the new view then enters with `duration-base` and `ease-out`, fading in from `space-6` on the other side. Moving to a later segment, views move toward the start; moving to an earlier one, toward the end; under `[dir="rtl"]` the directions mirror. Only transform and opacity; the height changes at once when the new view shows. A new selection during a run cancels it and the latest view enters; no view stays hidden. Under reduced motion: no movement; the old view fades out and the new one fades in, same durations.
- **Roles:** `role="radiogroup"` with an accessible name; each segment `role="radio"` with `aria-checked`; only the selected one has `tabindex="0"`.
- **Keyboard:** ← and ↑ move to the previous segment, → and ↓ to the next, and select it (from the last to the first); under `[dir="rtl"]` ← and → swap; Tab leaves the group.
