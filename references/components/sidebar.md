# Sidebar

**Uses:** Button, Menu, Avatar, Tooltip, Accordion, Top bar.

**Purpose:** the vertical navigation of an app, in a panel at the start edge of the screen.

- **Use:** a project's navigation is a Sidebar or a Top bar, never both: the project chooses, the screen size does not. Without a Top bar, the Sidebar holds the tools: Settings and the account row.
- **Hierarchy:** the rows come first, in their groups; the group titles only order them. The current page's row is the focal point (The One Winner Rule): the only one with a `surface-elevated` background, its label in `title-sm`; the other labels in `body-md` `ink`; the row icons and the group titles in `mute` only guide.
- **Elements:** the Sidebar's own: panel, header, logo, groups, group, group title, rail line, row, hit area, row icon, label, trailing, child list, guide, child list inner, child row, option, account wrapper, account row, account text, account name, account email. Other components: the collapse button and the phone menu button (Button, tertiary icon, with a Tooltip), the menu icon and the scrim (Top bar), the account Avatar (Avatar), the account and More menus (Menu), the rail tooltips (Tooltip).
- **Add-on files:** read only the file of each add-on that the part being built or checked contains: Child list `references/components/sidebar/child-list.md`, Settings group `references/components/sidebar/settings.md` with `references/components/sidebar/child-list.md`, More row `references/components/sidebar/more-row.md`.
- **Panel:** drawn inside its edge, no shadow, `space-2` from the screen's edges. position relative; width `sidebar`; height calc(100dvh − `space-4`); background `surface-card`; outline `line-thin` solid `hairline`; outline-offset −`line-thin`; border-radius `rounded-xl`; padding `space-3`; display flex; flex-direction column; gap `space-6`.
- **Fixed parts:** every part of the panel but the groups keeps its size: flex none.
- **Header:** the logo at the start, the collapse button at the end. display flex; align-items center; justify-content space-between; gap `space-2`.
- **Logo:** the project's logo used as it is (Start here, question 4), within a `space-10` square, always first. width `space-10`; height `space-10`; display grid; place-items center; color `ink`; font-family `title-lg`; font-size `title-lg`; font-weight `title-lg`; line-height `title-lg`; letter-spacing `title-lg`.
- **Collapse button:** an icon-only tertiary Button with the Hugeicons SidebarLeft icon in both states and `aria-expanded`; its accessible label and its Tooltip say the action: Collapse sidebar, or Expand sidebar in the rail.
- **Groups:** the only part that scrolls; the margin and the padding keep the rows' focus marks inside the scroll. flex 1; display flex; flex-direction column; gap `space-6`; overflow auto; margin calc(−`space-1`); padding `space-1`.
- **Group:** a `group` with `aria-labelledby` pointing to its title. display flex; flex-direction column; gap `space-2`.
- **Group title:** every group has one (Group titles in Hierarchy), `space-2` above its first row. position relative; height `space-6`; display flex; align-items flex-end; padding-inline `space-3`; margin-bottom 0; color `mute`; font-family `label-md`; font-size `label-md`; font-weight `label-md`; line-height `label-md`; letter-spacing `label-md`.
- **Row:** a link to a page, or a button for a row that opens in place; `space-2` from the next; the label starts `space-6` in from the panel's edge (The Radius-Padding Rule). position relative; display flex; align-items center; gap `space-4`; width 100%; height `space-10`; padding 0 `space-3`; border-radius `rounded-md`; color `ink`; text-align start; text-decoration none; font-family `body-md`; font-size `body-md`; font-weight `body-md`; line-height `body-md`; letter-spacing `body-md`.
- **Hit area:** the row's ::before, so the row reaches the Touch targets height. content ""; position absolute; inset calc(−`line-thick`) 0.
- **Row icon:** an `icon-md` icon before the label. color `mute`.
- **Label:** flex 1; white-space nowrap; overflow hidden.
- **Row hover:** only with a mouse (hover: hover): background `surface-hover`.
- **Pressed row:** background `surface-pressed`.
- **Current row:** the current page, with `aria-current="page"`. background `surface-elevated`; font-family `title-sm`; font-size `title-sm`; font-weight `title-sm`; line-height `title-sm`; letter-spacing `title-sm`.
- **Row focus:** a row shows the link focus underline on its label (States), the rows that open in place too. On :focus-visible: outline none, changed in 0s; text-decoration underline `line-thick` and text-underline-offset `space-1` on the label. The corner marks of States show only in the rail: elsewhere the row's ::after is display none.
- **Account wrapper:** the Menu's wrapper of the account row, last in the panel, so the profile menu is placed against the row: position relative; display flex; its Tooltip's wrapper: width 100%.
- **Account row:** a button that opens the profile Menu: a default Avatar, the name and the email, and an `icon-sm` up-down chevron. Its focus shows the corner marks of States, following `rounded-md`. display flex; align-items center; gap `space-3`; width 100%; height calc(`space-12` + `space-2`); padding 0 `space-2`; border-radius `rounded-md`; text-align start.
- **Account row hover:** only with a mouse (hover: hover): background `surface-hover`.
- **Pressed account row:** background `surface-pressed`.
- **Account text:** flex 1; min-width 0; display flex; flex-direction column.
- **Account name:** color `ink`; font-family `title-sm`; font-size `title-sm`; font-weight `title-sm`; line-height `title-sm`; letter-spacing `title-sm`; white-space nowrap; overflow hidden; text-overflow ellipsis.
- **Account email:** color `mute`; font-family `body-sm`; font-size `body-sm`; font-weight `body-sm`; line-height `body-sm`; letter-spacing `body-sm`; white-space nowrap; overflow hidden; text-overflow ellipsis.
- **Menus:** every menu of the sidebar (account, More) opens on the end side of the panel, `space-2` past its edge. The profile menu ends on the bottom of its row, the others start on the top of theirs, and all stay inside the screen.
- **Rail:** the collapsed panel, so narrow that the icons sit at its centre. The state is remembered. width calc(2 × `space-8` + `space-1`).
- **Rail header:** the logo: display none; the collapse button takes its place.
- **Rail rows:** only the icons remain, and the rows keep their padding, so the icons do not move. The label and the trailing: display none. Focus shows the corner marks of States, following `rounded-md`, since there is no label to underline.
- **Rail line:** the group title's ::before. In the rail the title keeps its height and its text gives way to the line: the title: color transparent; the line: opacity 1. content ""; position absolute; inset-inline `space-3`; top 50%; height `line-thin`; background `hairline`; opacity 0; transition opacity `duration-fast` `ease-out`.
- **Rail tooltips:** in the rail every row has a Tooltip with its label on the end side, `space-2` past the panel's edge: the Tooltip's wrapper: display flex; justify-content center; width 100%; the Tooltip: inset-inline-start calc(100% + `space-3` + `space-2`). Outside the rail: display none.
- **Rail groups:** overflow visible, so the tooltips are not clipped.
- **Rail account row:** only the Avatar remains, with a Tooltip naming the account menu; it opens the profile Menu, the only menu of the rail. justify-content center; padding 0; the account text and the chevron: display none; with a mouse, no hover background.
- **Rail motion:** collapsing and expanding never move what stays visible: the panel keeps its layout and its end edge is clipped from `sidebar` to the rail's width with clip-path, as the Top bar's panel; never animate its size (Motion). The clip runs in `duration-base`, with `ease-in` to collapse and `ease-out` to expand. While it moves, the labels, the chevrons, the group titles' words and the account's name and email fade out or in, in `duration-fast`. The collapse button moves to the logo's place and the content beside the sidebar slides, both with FLIP (transform), with the same timing. Under reduced motion: no movement, the labels fade in.
- **Phones:** below `md` there is no rail and no collapse button: the panel is not on the page until the menu button opens it as the navigation panel.
- **Menu button:** only below `md`: the Top bar's menu button, icon-only, `button-lg` square, with its menu icon (three lines that turn into an X), label and Tooltip Open menu, or Close menu while the panel is open. It is drawn over the page, at the top start of the screen. display inline-flex; position fixed; top calc(`space-4` + env(safe-area-inset-top)); inset-inline-start `space-4`; z-index `zIndex-raised`; the button: background `surface-float`; outline `line-thin` solid `hairline`; outline-offset −`line-thin`.
- **Navigation panel:** below `md`: the expanded panel over the scrim (Top bar), `space-2` from the screen's edges and the safe areas; the menu button stays in place above it. position fixed; top calc(`space-2` + env(safe-area-inset-top)); bottom calc(`space-2` + env(safe-area-inset-bottom)); inset-inline-start `space-2`; height auto; z-index `zIndex-base`, under the menu button.
- **Navigation panel header:** it lines up with the menu button, the logo `space-4` after it. margin-block-start calc(−`space-1`); height `button-lg`; padding-inline-start calc(`space-4` + `button-lg` + `space-4` − `space-2` − `space-3`). The collapse button's Tooltip wrapper: display none.
- **Navigation panel closed:** past the screen's start edge, and hidden once it has closed: translate calc(−100% − `space-2`) 0, under `[dir="rtl"]` calc(100% + `space-2`) 0; transition translate `duration-base` `ease-in`; visibility hidden.
- **Navigation panel open:** it slides in from the start edge and the scrim fades in with it. translate none; transition translate `duration-slow` `ease-out`. Until it has closed, the sidebar holding the menu button and the panel sits above the scrim, at position relative; z-index `zIndex-modal`; the page below does not scroll. The profile menu opens above the account row, as wide as the row, `space-2` from it.
- **Navigation panel reduced motion:** no movement: translate none; opacity 0, and opacity 1 when open; the same durations and easings.
- **Markup:** `<nav aria-label="Sidebar">`; Tab moves through the rows; Enter or Space opens a row with children. Options are radios in a `radiogroup`.
- **Phone keyboard:** the menu button is a disclosure with `aria-expanded` and `aria-controls` pointing to the panel. While the panel is open, Tab stays inside the button and the panel; Escape, a link, the scrim or the menu button closes it, and focus returns to the menu button.
