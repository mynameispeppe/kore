# Cards

- **Clickable hover:** Replaces: `cards.clickable-hover`. On mouse hover (hover: hover), a clickable card that is not a cover: transform none; background-color `surface-hover`; transition background-color `duration-fast` `ease-out`. With reduced motion, transition 0s.
- **Cover card:** Replaces: `cards.cover-card`. As in `references/components/cards/cover.md`, without the shadow and the lift (transform none on hover). The cover text's ::before carries a second `veil-cover` veil, the same as the first, background-position bottom; background-repeat no-repeat; background-size 100% 0 at rest; on mouse hover (hover: hover) background-size 100% 100%, so it rises from the photo's bottom to the full height of the first, since the photo hides any background; transition background-size `duration-fast` `ease-out`; with reduced motion, transition 0s.
