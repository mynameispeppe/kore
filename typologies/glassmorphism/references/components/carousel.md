- **Indicator mark:** Replaces: `carousel.indicator-mark`. As in the default, with the inner glass of Glass inside glass and no shadow: background `glass-inner-background`.
- **Current mark:** Replaces: `carousel.current-mark`. As in the default, with the fill of the filled Button over the inner glass: background linear-gradient(color-mix(in srgb, `primary` `glass-button-fill`, transparent)), `glass-inner-background`.

- **Snap card:** Replaces: `carousel.snap-card`. As in the default, with the Glass recipe whose box-shadow keeps only the glass's edges: box-shadow inset 0 1px 0 `glass-edge-top`, inset 0 0 0 1px `glass-edge`.
